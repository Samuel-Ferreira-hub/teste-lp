# Origem — Landing Page

Landing page da Origem (moda feminina versátil e atemporal).
Arquivo único, sem build: `index.html`.

## Publicar no GitHub Pages
1. Suba `index.html` na raiz do repositório.
2. Settings → Pages → Source: `Deploy from a branch` → branch `main` / pasta `/ (root)`.
3. A página fica em `https://<usuario>.github.io/<repo>/`.
